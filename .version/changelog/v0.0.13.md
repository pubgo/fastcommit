## 修复

- 修复 `fastgit commit` AI 生成无超时导致 spinner 卡死的问题（HTTP/请求约 45s，超时回退规则消息）。
- 修复大 diff 直接送给 AI 易超限/失败的问题：提交前自动压缩 diff（跳过 lock/二进制，限制体积）。
- 修复无意义的 `git reset --soft HEAD`；仅在存在 `chore: quick update` 连续提交时才 squash。
- 调整 commit 顺序为先 check/AI，再 soft-reset squash，避免失败后留下半成品状态。
- 修复 `git commit -m` 经 shell 引号拼接导致带 `'`/`"` 的 message 异常；改为直接 exec。
- 修复 push 被拒后 `os.Exit(1)`，改为返回可读错误。
- `pull --hard` 在脏工作区时明确警告将丢弃未提交改动。

## 验证建议

- 运行 `fastgit check run`
- 小改动执行 `fastgit commit --single --skip-check`，确认可正常出 message
- 大 diff 提交时日志出现 abbreviated patch，且不会长时间卡死
- `fastgit pull` 脏树应拦截；`fastgit pull --hard` 应打印丢弃警告
