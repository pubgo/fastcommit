# [v0.0.15] - 2026-08-18

## 修复

- 修复没有 `.fastgit/check.yaml` 时 commit 仍跑硬编码 Go 检查流水线的问题；无配置文件时不再运行 pre-commit check。
- `--fast` 模式下 check 自动修复格式问题（`gofmt -w`），不再报错阻断提交。

## 变更

- pre-commit check 行为改为配置驱动：无 `.fastgit/check.yaml` = 不检查。
- 检测到配置文件时，打印配置文件路径。
- `fastgit check config` 无配置文件时提示 `check is disabled` 并告知如何创建。
