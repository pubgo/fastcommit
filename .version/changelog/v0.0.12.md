# [v0.0.12] - 2026-08-10

## 新增

- 新增团队治理命令 `fastgit team`，支持下发 `.fastgit/policy.yaml` / `commit.yaml` / `check.yaml`。
- 新增质量门禁 `fastgit check`（run/config/hook），支持 staged-only、dry-run、secret scan。
- 新增 PR 闭环 `fastgit pr`（create/status/sync/merge），支持 AI 润色与本地 review 联动。
- 新增本地评审 `fastgit review staged`（AI + 规则 fallback）。
- 新增冲突助手 `fastgit conflict`，支持 AI 冲突原因摘要。
- 统一 `AIProvider` 抽象（OpenAI / Copilot / fallback / 可选缓存）。
- Desktop：远程 relay push、commit log、tag 删除等能力增强。

## 修复

- 修复 `fastgit commit` 默认使用 `git add --update` 导致新建未跟踪文件无法进入提交的问题，改为 `git add -A`。
- 修复 check 失败时误报 `check passed`，改为输出失败阶段与摘要。
- 修复多处 `WriteString(fmt.Sprintf(...))` lint 问题，并清理未使用的冲突检测函数。

## 变更

- Copilot 权限策略统一：CLI / env / config / agentline TUI 共用 `ask|allow|deny`。
- `commit` 默认启用多候选提交信息（可用 `--single` 关闭）。
- changelog release 增加影响/验证/回滚元信息与 bump 一致性校验。

## 文档

- 补充 `architecture.md` / `features.md` / `roadmap.md` / `INDEX.md`，覆盖闭环场景与配置优先级。

## 影响范围

- CLI：`commit` / `check` / `pr` / `review` / `conflict` / `team` / `copilot` / `changelog`
- Desktop：远程操作与 tag 管理相关界面

## 验证建议

- 运行 `fastgit check run`
- 验证 `fastgit commit` 可提交新建未跟踪文件（非 ignore）
- 验证 `fastgit pr create --dry-run` 与 `fastgit review staged --dry-run`

## 回滚建议

- revert 相关 commit 或关闭未合并 PR
- 如已安装 check hooks，可用 `fastgit check hook uninstall` 回退
